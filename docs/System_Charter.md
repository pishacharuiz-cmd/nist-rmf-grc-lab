# System Charter: Project-Alpha-Portal

## 1. Purpose & Overview
Project-Alpha-Portal is a customer-facing web application designed to handle secure user authentication, account management, and sensitive transactional data processing for enterprise clients.

## 2. Stakeholders & Roles
* **Authorizing Official (AO):** Director of Information Security
* **Information System Owner (ISO):** Lead Application Architect
* **Information System Security Officer (ISSO) / GRC Analyst:** Compliance & Risk Management Lead

## 3. Operational Environment
* **Hosting Model:** Cloud-hosted virtualized Linux environment.
* **Data Classification:** Moderate-risk Personally Identifiable Information (PII) and authentication credentials.
* **Compliance Scope:** NIST SP 800-53 Rev. 5 Moderate Control Baseline.
